# AI Live Commentator — ブラウザ版 v1.0

OBSの映像からGemini 3.1 Flash-Liteが短いコメントを作る、サーバー不要のローカルブラウザアプリです。ZIPを展開して `index.html` を開きます。インストール・ビルド・Node.js・.NETは不要です。

## まず使う

1. ZIPを**すべて展開**し、`index.html` を同じWindows PCのChromeまたはEdgeで開きます。`core.js`・`app.js`・`style.css`を同じフォルダに置いてください。ZIP内から直接起動しないでください。
2. OBSと読み上げソフトを起動します。既存のWindows版実況アプリは停止しておきます。
3. OBSでWebSocketサーバー（5.x、通常4455）を有効化。接続先・OBSパスワード・OBSの映像ソース名を入力し、**映像確認**を押します。
4. **読み上げ先**を選んで**音声テスト**を押します。以下の2方式に対応しています。
5. Gemini APIキーを入力し、そのキーの所属プロジェクトがFree Tier・課金未設定であることを確認してチェックします。
6. **実況を開始**を押します。初回は画像を2枚取得してから解析します（標準では最初の取得から約8秒後）。

Windows版の設定ファイルは自動では読み込みません。接続情報を入力し直してください。ChromeとEdgeや、移動したフォルダでは、保存設定を共有できない場合があります。

## 読み上げ

### 棒読みちゃん（初期選択・PC側で再生）

- 棒読みちゃんの**設定 → システム → アプリケーション連携 → HTTP連携**で「ローカルHTTPサーバ機能を使う」を有効にします。通常はポート50080です。
- ブラウザ側のURLは `http://127.0.0.1:50080`。**声のID＝0**は棒読みちゃんで選択中の声を使います。ブラウザ内の話者スタイルIDとは別の番号です。
- 公式配布の **0.1.11.0 Beta21** にはFetch APIからの接続対応が記載されています。古い版でつながらない場合は公式配布版を確認してください。
- VOICEVOXの声を使うには、棒読みちゃん側でVOICEVOX連携を設定し、その声を選んでおきます。このZIPにプラグインや音声は同梱していません。
- 棒読みちゃんの再生待ち件数が0でなければ、そのコメントを見送ります。他のアプリの音声待ちを勝手に消去しません。
- ブラウザの表示は**送信済み**であり、棒読みちゃんでの合成・再生完了までは確認できません。音声テストは実際に聞いて確認してください。
- 停止ボタンは新しい解析・送信を止めます。**すでに棒読みちゃんに送った音声は、棒読みちゃん側で停止する必要がある場合があります。**
- モデル出力に含まれる括弧・タグ・コマンド構文などは除去して送信します。棒読みちゃん側の辞書やプラグインによる読み替えは、そちらの設定に従います。
- OBSは棒読みちゃんのアプリ音声、または適切なデスクトップ音声を取り込みます。

### VOICEVOX直接（今までの構成に近い方式）

- VOICEVOXを起動し、URLを `http://127.0.0.1:50021` に設定します。
- 話者スタイルIDは初期値3。音声を合成して**このブラウザで再生**します。
- OBSはChrome/Edgeのアプリ音声を取り込みます。二重取り込みに注意してください。
- ブラウザからの呼び出しがVOICEVOX側のCORS設定で拒否されることがあります。エラーが出た場合はVOICEVOX側の許可設定を確認するか、棒読みちゃん経由を使用してください。ブラウザのセキュリティ機能を無効にしないでください。
- 開始・音声テストをクリックした時にブラウザの音声再生を有効化します。再生が許可されない場合は、タブのミュートや音声設定を確認してください。

## 頻度・鮮度

| 項目 | 初期値 | 動作 |
|---|---|---|
| おしゃべり度 | よく話す | 控えめ／標準／よく話す。後者は移動中の感想・相づちも積極的に作る |
| API送信の最短間隔 | 30秒 | この間隔より短く解析を要求しない |
| 発言の最短間隔 | 20秒 | VOICEVOX直接は再生終了、棒読みちゃんは送信完了からの最短時間 |
| 変化が少ない時の解析 | 60秒 | 変化が少なくても解析。ただしAPI最短間隔を優先 |
| 画像取得間隔 | 8秒 | OBSからのローカル取得。取得だけではGeminiを呼び出さない |
| 送信画像の横幅 | 640px | 320／640／960px。JPEG品質75、前後2枚 |
| 今回の送信上限 | 20回 | 失敗・破棄も含む試行数。到達したら停止 |
| コメントの鮮度上限 | 15秒 | 5〜180秒。現在画像の取得開始からの時間 |
| 503時は待って再開 | OFF | ONなら30秒→60秒待機、連続3回で停止。API最短間隔が長ければそちらを優先 |

「よく話す設定」ボタンは、おしゃべり度・API間隔・発言間隔・静かな場面の間隔を初期値にします。送信上限・鮮度・503設定には触れません。設定の変更は停止中に行い、「設定を保存」または「実況を開始」で保存します。

### 遅れて届いたコメントを読み上げない

- 鮮度上限までにGeminiが返らなければ、その要求の待機を中断します。同じ画像での即時再送はしません。次の通常の解析タイミングまで待ちます。
- 返った時点と音声出力の直前にも経過時間を確認します。
- VOICEVOX直接では、音声の生成・読み込みにかかった時間も含め、上限までに再生を始められなければ破棄します。
- **棒読みちゃんは送信直前までの鮮度を判定**します。送信後のPC側の合成や再生開始時刻は保証できません。棒読みちゃんへの送信途中で期限になった場合も、すでに受け付けられている可能性があります。
- 15秒で破棄が多い場合は30秒などに調整できます。上限を長くするほど古い場面への発言を許容することになります。
- ブラウザで通信を中断しても、Google側の処理が取り消されたことや、利用枠を消費しないことを保証するものではありません。送信試行は1回として数えます。

画像取得・解析・読み上げは順番に処理します。バックグラウンドタブの節電、スリープ、音声合成時間などにより実際の間隔は設定より長くなります。連続映像やゲーム音を理解するものではありません。画像の誤認や出来事の見逃しはあり得ます。

## 接続・遅延の切り分け

- **映像確認**：OBSのみ。画像が出るか、ゲームの画面だけか確認します。
- **音声テスト**：選択した読み上げ先のみ。Geminiには送りません。
- **文章だけで接続テスト**：同じGeminiモデルに短い文章を1回送り、所要時間を表示します。画像・音声は使いません。これはAPI送信を1回使います。上限に含め、503でも自動再送しません。診断なので鮮度上限は適用せず、最大180秒待ちます。
- **直近のAPI応答**：実況のAPI応答時間。画像取得と音声合成の時間は含みません。
- **鮮度切れ**：古くなった要求・コメントの破棄回数。
- **実行履歴**：見送り理由、503の待機、HTTPエラーなどを表示します。生のエラーレスポンスやキーは出しません。

## 無料枠・データの扱い

使用AIは固定の **gemini-3.1-flash-lite**。別モデル・別会社への自動切り替えはありません。

- キーの所属プロジェクトがGoogle AI Studioで**Free Tier・課金未設定**であることを確認してください。アプリは課金状態やGoogle側の残枠を取得しません。有料プロジェクトのキーでは料金が発生する可能性があります。
- 頻度・日次回数などの上限はAI Studioで確認してください。「20回」はこのアプリの初期上限で、Googleの無料枠の値ではありません。
- 429、認証エラー、その他のHTTPエラーは停止します。503だけは明示的にONにした場合に限り待って再開します。再開時は画像を新しく2枚取得します。全送信試行は共通の上限内で行います。
- 「実況を開始」で今回のカウントは0になりますが、Google側の利用枠はリセットされません。接続テストもGoogleの利用枠を使います。
- ゲーム画像、キャラクター設定、最近の観察・発言がGoogleへ送られます。無料枠では製品改善に利用される条件があります。
- APIキーはGoogle宛てのHTTPヘッダーにのみ設定し、アプリは設定保存・履歴・URLには含めません。OBSパスワードも保存しません。秘密情報は入力欄・実行中のタブメモリーに保持します。
- 個人利用向けのローカルHTMLです。ブラウザ内にキーが存在する方式なので、利用中の端末や拡張機能を信頼できる環境で使用してください。キーを埋め込んで配布する構成ではありません。
- JavaScript・CSS・フォントの外部CDN、広告、アクセス解析は使用していません。
- 同じWindows PCのループバックURLに対応します。スマホからの遠隔操作・外部公開用の版ではありません。

## ブラウザの接続制限

ページがローカルネットワークへの接続許可を求めた場合は、指定した自分のOBS／読み上げソフトへの接続であることを確認してください。失敗時に`no-cors`で成功したように見せたり、セキュリティ機能を無効にしたりする処理はありません。組織管理ブラウザなどでローカルファイルからの接続が禁止されている場合は、その制限下では動作しません。

## ファイル

- `index.html`：起動するファイル
- `style.css`：画面デザイン
- `core.js`：OBS接続、Gemini通信、鮮度・間隔・エラー処理
- `app.js`：操作画面、実況ループ、棒読みちゃん／VOICEVOX出力
- `tests/`：開発用テスト（利用時は不要）

基本テストは11件、ブラウザ操作テストは11シナリオを実行しました。HTMLをfile://で直接開き、OBS認証と画像取得、棒読みちゃん送信、VOICEVOXのWAV再生、鮮度切れ（解析中／合成中）、停止後の遅延応答、429停止、503待機と上限、設定から秘密情報を除外する処理を模擬サービスで確認しています。Googleや実際のローカル音声ソフトへの送信はしていません。

基本テストにはNode.jsを使います：`node --test tests/core.test.cjs`

画面テストは開発者向けです。PlaywrightとChromiumを用意し、`node tests/browser.test.cjs` を実行します。必要に応じて環境変数 `CHROME_PATH` で実行ファイルを指定します。スクリーンショットはこのフォルダの隣の `.browser-test/` に保存します。

実際のWindows上のOBS・棒読みちゃん・VOICEVOXと、利用者のキーによるGemini応答はこの環境では確認できません。最初は映像確認・音声テスト・少ない送信上限で接続を確認してください。

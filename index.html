    準備・接続・トラブルシューティング

    準備とトラブルシューティング

    はじめに

    フォルダ内の index.html を、操作するPCのChrome・Edgeで開きます。専用サーバーは不要です。「映像確認」「音声テスト」を試し、Geminiのキーを設定して開始してください。

    VOICEVOX：Windows版では鳴るのにブラウザでは失敗する

    開発者ツールに origin 'null'、CORS、403 Forbidden が出る場合は、VOICEVOXを起動し、VOICEVOXエンジンの設定を開きます（設定したVOICEVOX URLの設定画面）。CORS Policy Mode を localapps、Allow Origin に null を追加し、保存してVOICEVOXを再起動してください。ほかの許可設定は必要に応じて残します。その後、音声テストをやり直します。

    null の許可は、このアプリ以外のローカルファイルや一部の隔離されたページにも適用されます。信頼できないHTMLを同時に開かず、使わなくなったら許可を外してください。CORSを all にしたり、ブラウザの保護を無効化したりする必要はありません。

    読み上げ先に接続できない・音が出ない

    起動状態、URLとポート、ブラウザのローカルネットワーク許可、OSの音量を確認してください。VOICEVOX直接は操作しているブラウザで再生します。棒読みちゃんは設定のHTTP連携を有効にし、PC側の声・音量を確認します。声が異なる場合は「友達」タブのスタイルID・声IDを、速すぎる・遅すぎる場合はVOICEVOX話速を見直してください。

    OBSにつながらない・映像が違う

    OBS → ツール → WebSocketサーバー設定で有効化。URL、パスワード、OBSに登録された映像ソース名を確認してください。配信全体ではなくゲームだけを取得するソースがおすすめです。「取得した映像」にある「映像ソースを再取得」は、指定したOBS入力の設定を変更せずに再適用し、ウィンドウキャプチャの対象を探し直させます。PS Remote Playなどで同名のランチャーからプレイヤーへ切り替わらない場合に試してください。

    OBSにコメントを表示する

    「接続 → OBS・映像 → コメント表示」でONにすると、現在のOBSシーンに「みんコメ 吹き出し」という Browser Source を必要時に自動作成します。角丸・影・しっぽを付けた吹き出しは、短文ではテキスト量に合わせて小さくなり、長文では最大幅で折り返します。表示位置、フォント、文字サイズ、友達名の表示ON/OFF、太字ON/OFF、発言後の表示時間を設定できます。文字には友達色を濃くしたエッジを自動で付けます。フォント一覧は管理画面で自由に追加・削除でき、初期状態はシステム標準だけです。登録名のフォントがOBS側PCにない場合は代替フォントを使います。表示時間が終わるとシーンアイテム自体を非表示にするため、背景だけ残りません。シーンを切り替えた場合は、そのシーンにも同じソースを自動追加します。VOICEVOX直接は発話中から表示し、棒読みちゃんはPC側の実再生時刻を取得できないため、読み上げ要求を送信した時点の最新コメントを表示します。

    Geminiが遅い・503・429が出る

    503・通信エラーなどは5秒後に再開します。429は配信を止めず、30秒 → 60秒 → 120秒 → 300秒と間隔を広げ、その後は最大5分ごとに再試行します。Googleの構造化されたRetryInfoをRetry-Afterより優先し、サーバー指示が5分を超えていても自動再試行の間隔は最大5分です。元の待機指示は履歴に残します。正常応答が返れば429の連続回数をリセットします。待機中もOBS画像の取得は続き、再試行時点の最新映像で再開します。429には短時間の頻度制限だけでなく日次クォータ不足もあり、その場合は再試行してもリセットまで成功しません。Google側の上限を回避する機能ではありません。

    401・403など認証や設定の問題は、同じ要求を繰り返さず修正待ちになります。設定を直し「設定を適用して再開」を押してください。いつでも「停止」で終了できます。接続・音声テストは単発の診断です。

    対象コンテンツと追加知識

    「実況」タブの対象コンテンツで「管理」を開くと、各コンテンツの「知識」からその項目専用の追加知識を編集できます。固有名詞、人物、場所、ゲームシステム、略称など、画面だけでは判断しにくい情報を登録してください。追加知識は選択中のコンテンツにだけGeminiへ渡し、別のコンテンツには引き継ぎません。登録内容は参考情報として扱い、画像や現在の状況と矛盾する場合は画面側を優先します。空欄で保存するとそのコンテンツの追加知識を削除します。

    画像取得・解析・読み上げのタイミング

    画像取得・Gemini解析・読み上げは独立して動きます。取得周期は「前回の取得完了から待つ」のではなく、前回の取得開始時刻を基準にします。たとえば1秒間隔・4枚なら、解析時点のおおむね直近3秒ぶんの流れを送ります。VOICEVOXで発言中でも画像履歴は更新され、API送信条件を満たせばGemini解析も1本だけ裏で進みます。未再生の解析結果は最新1件だけ保持し、より新しい結果が来れば差し替えます。VOICEVOXの現在の掛け合いが終わった時点で候補が鮮度内なら、発言間隔を再度待たず続けて再生します。画面変化が少ない状態が続いても、最初の低変化解析は通常実況のままです。低変化の解析が2回連続した時点から雑談モードになり、進行を急かさず、対象コンテンツ・現在画面の雰囲気・最近の状況から友達同士の自然な雑談を優先します。過去の別リクエストの発言は重複回避の参考だけにして、そこへの返事として新しい発言を始めません。「本当だね」「そうだね」「たしかに」等の同意相づち始まりも避けます。飲み物・食事・休憩・席を立つ等の生活ネタは、画面や現在の状況にきっかけがない限り埋め草にしません。棒読みちゃんはPC側の実再生完了をブラウザから確認できないため、同じ精度で「話し終わり」へ同期はできません。実行中の秒表示は処理ステータスの経過時間ではなく「最終取得から何秒前か」を表示します。

    鮮度切れ・発言が少ない

    古い映像への発言を防ぐため、現在画像の取得開始から鮮度上限を超えた応答・音声を破棄します。Gemini待ちが鮮度上限に達した時点で待機を即打ち切り、鮮度切れをカウントして、待機時間を挟まず取得済みの最新映像から再解析します。読み上げ用テキストは、原則として漢字をかなへ、英字略語をカタカナ読みへ、数字を文脈に合う自然な読みへ変換してGeminiの最初の応答で生成します。読み上げ用テキストの品質だけを理由にGeminiへ再生成は行わないため、映像に対するコメントの鮮度を優先します。読み上げ用テキストが表示文と同じ、欠落、空欄、記号だけなど想定どおりでない場合でもコメント自体は破棄せず、使える読み上げ文または表示用テキストで必ず読み上げを続けます。読みが不確かな固有名詞などは漢字・英数字が残ることがあります。まず画像幅320pxや、鮮度上限を少し長くする設定を試せます。「よく話す設定」も利用できます。鮮度を確認するのは会話の最初の発言が始まるまでです。開始できた掛け合いは後半も最後まで再生します。停止ボタンや通信エラー・通常のタイムアウトでは途中でも中断します。

    発言人数の重み

    通常実況・開始挨拶・終了挨拶では、1〜6人それぞれの重みから毎回「今回の発言人数」を抽選します。Geminiにはspeakの真偽にかかわらず抽選人数ぶんの候補発言を生成させ、通常実況ではspeak=trueの時だけ読み上げます。これにより「無言」と「人数指定」のJSON構造が競合しません。開始・終了挨拶を有効にしている場合はspeakの値に関係なく候補を読み上げ、生成結果が2回続けて不正なら固定の短い挨拶へフォールバックします。通常実況では直近の話者履歴も渡して、同じ人への偏りを抑えます。

    開始・終了の挨拶

    「実況開始時に短い挨拶」を有効にすると、監視開始前にGeminiが短い挨拶を生成します。話す人数の上限は通常実況と同じ重み設定から毎回抽選します。開始時はゲーム内容をまだ断定しません。挨拶は毎回「期待型」「雑談開始型」「余韻型」など複数の方向性から1つを選び、直近の開始／終了挨拶も少数だけブラウザ内に記録して、同じ入り方・語尾・意味の繰り返しを避ける材料として使います。複数人の場合は全員が別々の挨拶を並べるのではなく、短い掛け合いになるよう依頼します。「実況を終了」は映像監視を止め、今回の直近履歴と同じ人数重みを使った締めの挨拶を再生してから終了します。「即停止」は挨拶を生成せず、通信・ブラウザ音声をすぐ停止します。開始・終了の挨拶もGemini API送信回数に含まれます。

    友達の掛け合い

    友達1〜6から今回参加するメンバーを個別に選びます。選択した全員を毎回話させるわけではなく、その場に合う1人以上が短く発言します。「直近のコメント」とその下の「読み上げ」は、VOICEVOX直接では実際の音声再生開始と同時に更新します。棒読みちゃんはPC側の実再生開始時刻をブラウザから取得できないため、読み上げ要求の送信成功時に更新します。「直近のコメント」の横（狭い画面では下）には、参加中の友達ごとの発言状況・今回の発言回数・割合を、ドーナツグラフと凡例で表示します。実況開始時に0へ戻り、開始・終了挨拶を含め実際に読み上げ／送信まで到達した発言を集計します。1回のAPI応答で最大6発言を生成します。「会話履歴として送る発言数」で、直近の誰が何を言ったかをGeminiへ渡す件数を0〜20発言から指定できます。履歴がある場合も相づち自体は禁止せず、同意だけの反応が続きすぎないよう会話の偏りを抑える材料として使います。VOICEVOX直接は現在の発言を再生しながら次の1発言だけ先読み生成し、発言間の待ち時間を短縮します。棒読みちゃんは順番にキューへ送るため、ほかのアプリの発言が混ざる場合があります。送信済み音声の停止は棒読みちゃん側で行ってください。

    設定のインポート・エクスポート

    「設定をエクスポート」で、実況・接続・読み上げ・OBS吹き出し・友達6人の名前／性格／声／話速・参加メンバー・発言人数の重み・対象コンテンツ一覧・コンテンツ別の追加知識・登録フォント一覧をJSONファイルに書き出せます。「設定をインポート」でそのJSONを読み込み、現在の通常設定を置き換えます。Gemini APIキー、OBSパスワード、Free Tier確認状態、暗号化保存データは書き出さず、インポートでも変更しません。

    保存とロック

    通常設定はブラウザ内に保存します。キーとOBSパスワードは「暗号化して保存」を選んだ場合だけ、合言葉で暗号化して保存します。AES-GCM 256bit、PBKDF2-SHA256 60万回を使用し、合言葉は保存しません。解除中のページやPC自体が侵害された場合まで守る機能ではありません。ブラウザデータの削除・フォルダ移動・別ブラウザでは保存情報が利用できなくなることがあります。

    同じLAN内の別PCへ接続する

    接続先PCのIPv4を指定します（例: OBSは ws://192.168.1.10:4455、VOICEVOXは http://192.168.1.10:50021、棒読みちゃんは http://192.168.1.10:50080）。許可範囲は10.x.x.x、172.16.x.x〜172.31.x.x、192.168.x.xです。PC名ではなくIPアドレスを使ってください。

    接続先PCで各ソフトをLANから接続できる待受状態にし、Windowsファイアウォールのプライベートネットワークで必要なTCPポートをローカルサブネットから許可します。ルーターのポート開放は不要です。OBSは認証を有効にし、ゲストWi-Fiなど端末間通信が禁止されていないかも確認してください。

    VOICEVOXのエンジンが127.0.0.1だけで待ち受けている場合は、LANのIPで待ち受ける起動設定が別途必要です。エンジンの --host にPCのLAN IPを指定する方法があります。CORS許可も引き続き必要です。棒読みちゃんもHTTP連携がLANから接続を受け付ける構成か確認してください。

    VOICEVOX直接は接続先PCで音声を合成し、操作中の端末で再生します。接続先PCから音を出したい場合は棒読みちゃんを使います。HTTPSで公開したページからの ws/http 接続はブラウザに拒否される場合があります。ローカルHTMLでの利用を基本とし、ブラウザの保護を無効化しないでください。

    スマホ・外出先・長時間の利用

    画面はスマホ幅にも対応し、同じLAN内のPCへも接続できます。接続にはブラウザの制限と接続先ソフトの設定が影響します。外出先からのインターネット経由の接続には対応していません。タブを閉じると終了し、非表示・スリープ・画面ロックで監視や音声が中断することがあります。無人での常時稼働は保証できません。

    対象コンテンツを管理

    「メイン項目：サブ項目」で階層化できます。メイン項目も選択できます。

    このコンテンツだけで使う追加知識です。固有名詞、人物、場所、ゲームシステム、よく使う略称などを書けます。

    空欄で保存すると、このコンテンツの追加知識を削除します。

    OBS吹き出しフォントを管理

    OBSを動かすPCにインストール済みのフォント名を登録してください。プレビューを開くだけでは確実ではないため、追加後はOBSを再起動すると確実です。
